# BigModeGameJam2025

Developed with Unreal Engine 5

This project was developed for the 2025 BigMode GameJam, and eventually became a game known as "Out For Blood"

The game is a first person shooter which implements a token-based AI system found in games such as Doom (2016) that operates with an economy of "tokens" that AI agents share amongst each other to decide their behavior. These tokens are spent when the enemies take actions and returned when said actions are completed. This system allows the enemies to ensure they don't all attack at once and overwhelm the player and allows for certain actions to cost tokens to affect which attacks can occur at the same time. For instance, a large heavy enemy with a powerful attack will use all the tokens in the pool preventing any other enemies from attacking while it is occurring, allowing that enemy to take the players attention for that time.
